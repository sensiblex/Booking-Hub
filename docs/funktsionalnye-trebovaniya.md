# Функциональные требования

## Общие требования

Система должна иметь веб-интерфейс, адаптированный для работы с десктопных и мобильных устройств.

## Роль «Гость»

- Просмотр списка всех помещений (название, фото, описание, базовая цена);
- Просмотр детальной информации о помещении (фото, описание, оборудование, правила);
- Регистрация: ФИО, логин, e-mail, пароль, номер телефона.

## Роль «Клиент»

- Вход в систему по логину/e-mail и паролю;
- Поиск свободных помещений по критериям:
  - Тип (переговорная, рабочий стол, офис);
  - Дата и время;
  - Количество гостей;
  - Наличие оборудования (проектор, монитор, маркерная доска);
- Бронирование выбранного помещения на временной слот;
- Добавление дополнительных услуг (проектор, мебель, кофе-брейк);
- Онлайн-оплата через интегрированную платёжную систему;
- Просмотр истории бронирований и их статуса (активно / завершено / отменено);
- Отмена будущего бронирования (с возвратом средств при отмене за N часов).

## Роль «Менеджер»

- Просмотр полной сетки бронирований (календарь / таблица);
- Добавление нового помещения в каталог (название, описание, тип, вместимость, цена, фото);
- Редактирование и деактивация существующих помещений;
- Просмотр, редактирование и отмена любых бронирований клиентов;
- Формирование отчётов:
  - Загрузка помещений за выбранный период (%);
  - Финансовый отчёт по выручке.

## Роль «Администратор»

- Просмотр списка всех зарегистрированных пользователей;
- Изменение роли любого пользователя (назначить Менеджером);
- Блокировка (деактивация) учётной записи пользователя.
