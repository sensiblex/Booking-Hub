# Booking-Hub — Система организации и бронирования пространств

Учебный проект по дисциплине «Проектирование информационных систем».

## О проекте

Веб-система для автоматизации бронирования помещений (коворкинги, переговорные, офисы). Заменяет ручной учёт бумажными журналами на удобный онлайн-интерфейс.

**Стек технологий:**
- Backend: Python (Django/Flask), REST API
- Frontend: HTML5, CSS3, JavaScript
- БД: PostgreSQL / MySQL
- Взаимодействие: HTTP/HTTPS + JSON

## Роли пользователей

| Роль | Возможности |
|---|---|
| Гость | Просмотр помещений и тарифов, регистрация |
| Клиент | Поиск, бронирование, онлайн-оплата, история бронирований |
| Менеджер | Управление каталогом, подтверждение/отмена броней, отчёты |
| Администратор | Управление пользователями, ролями, настройки системы |
